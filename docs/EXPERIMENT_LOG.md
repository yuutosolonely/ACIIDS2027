# Experiment log

**Không có model/benchmark experiment nào được chạy trong lượt setup.** Kiểm phần mềm/setup nằm ở `docs/SETUP_VALIDATION.md`, không phải kết quả nghiên cứu.

Mỗi run sau này ghi: run ID; source commit + dirty/snapshot hash; config/hash; data/model revision; seed; information boundary; status; metrics/artifacts; hardware/time/cost; deviation. Run lỗi cũng ghi. Raw outputs tại `experiments/runs/<run_id>/` theo chính sách dữ liệu.
