# ref-verify

Use tools/verify_refs.py or aciids-lab verify_reference for public identifiers/titles. Compare exact title/year, author/venue on primary sources; scripts may not verify author list or publication venue. VERIFIED metadata means existence/identity, not support for the claim. Open the original methods/results and record section/table for each scientific statement. Record version/date/access failures. UNVERIFIED items cannot establish a contribution. Do not send private manuscript text to search. Never fabricate missing BibTeX fields; prefer publication metadata over preprint only when verified.
