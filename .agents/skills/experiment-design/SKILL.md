# experiment-design

Read docs/IDEA.md, experiment-plan and HARNESS. Map each RQ to data/information boundary, baseline, estimand, metric/CI and falsification criterion. Distinguish real errors, injected corruption and oracle controls. Require equal evaluation universe and declared label/compute budgets; rare valid patterns need a control. Freeze choices before test. Write only an assigned proposal/plan; substantive scope changes remain proposals until accepted. Hardware/checkpoints/cost unresolved means do CPU/design work and list the missing gate, not assume feasibility.
