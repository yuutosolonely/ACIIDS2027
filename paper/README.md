# Paper workspace
Chưa tạo manuscript hoặc kết quả. Hướng dẫn: `docs/PAPER_GUIDE.md`; prompt writer: `docs/prompts/WRITER.md`.
Lấy template Springer từ nguồn chính thức được dẫn trong conference context, ghi version/license. Tuân thủ định dạng Springer LNCS/LNAI (12-15 trang cho full paper). Không coi original abstract có placeholder là abstract kết quả đã hoàn thành.
